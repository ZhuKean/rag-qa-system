# Evaluation Report

Measured results of the full test suite against the project's stated
targets. All numbers below come from real end-to-end runs recorded in
`eval/` — no mocked numbers are presented as real.

## 1. Test environment

| Component | Choice |
|---|---|
| LLM | DeepSeek `deepseek-chat` (remote, OpenAI-compatible) |
| Embeddings | BAAI/bge-m3 (local, bilingual) |
| Vector store | Chroma (cosine / HNSW), 27 chunks |
| Retrieval | top_k=8, distance threshold 0.65 (strict <), reranker off, temperature 0.1 |
| Runner | `python -m eval.run_eval_v2` (36 questions, 8 categories) |

## 2. Test corpus

Synthetic internal-knowledge corpus, generated by
`scripts/build_corpus.py` (deterministic, reproducible), ingested with
`python -m scripts.ingest --reset`. 11 files → 27 chunks, 0 failures.

| File | Format | Purpose |
|---|---|---|
| `handbook_cn.txt` / `handbook_en.txt` | TXT | Bilingual employee handbook (mirror content) |
| `handbook.txt` | TXT | Original single-language handbook |
| `faq.md` | MD | FAQ with overlapping facts (citation ambiguity) |
| `policy_it_security.docx` | DOCX | IT security policy (password rules, data handling) |

| `office_directory.txt` | TXT | People & contact info (PII redaction stress) |

| `product_overview.txt` | TXT | Product overview (OOD-adjacent vocabulary) |

## 6. Known misses (not hidden)

* `multi_turn` 2/3 — one pronoun-resolution turn ("它和婚假有什么区别？")
  resolved the referent differently than intended; the answer itself
  stayed grounded and cited correctly.
* `bilingual_cn` 11/12 — one in-domain question was refused by the
  distance threshold (over-conservative refusal, not a hallucination).

## 7. Reproduce

```bash
python -m scripts.ingest --reset          # rebuild the corpus store
python scripts/preflight.py               # fail-fast config check
python -m eval.run_eval_v2 --output eval/results_v2_real.json   # 36-question suite
python -m eval.run_eval --output eval/results.csv              # ragas metrics
```

Exit code is non-zero if any category regresses vs. `eval/baseline.json`,
so the same command works as a CI gate.
